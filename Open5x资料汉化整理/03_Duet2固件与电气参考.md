# 03｜Duet2 固件与电气参考

## 先读此警告

`Duet2_Configuration/sys/config.g` 是上游 Prusa i3 原型的 RepRapFirmware（RRF）配置快照，首行标注为 `Open5x_ver_20211118`。它是理解控制结构和校准项目的参考，不是当前机器的刷写文件，也不能直接移植到 Klipper。

特别是当前工作区已有的设备使用 Octopus Max EZ、Klipper 与自定义五轴/RTCP 历史逻辑；其引脚、驱动器、轴名、归零策略、坐标变换和安全宏均与 Duet2 原型不同。

## 该原型的驱动映射

上游配置中的关键映射为：

```gcode
M569 P0 S0 ; X
M569 P1 S0 ; Y
M569 P2 S0 ; Z
M569 P3 S1 ; E0
M569 P4 S0 ; U
M569 P5 S0 ; V
M584 X0 Y1 Z2 E3 U4 V5
```

可按“驱动器 0–5 分别服务 X、Y、Z、E、U、V”的原型思路理解。`M569` 的方向值、`M584` 的映射和每个电机的实际相线/传动方向是一组配置，必须整体通过低速实测验证。

## 参数表：应理解，不应照抄

| 参数域 | 上游内容 | 移植时必须重新确定 |
|---|---|---|
| 细分 | 配置使用 16/32 细分设置 | 驱动器型号、插值、最高脉冲频率、噪声与扭矩 |
| 步距 | XY/Z/E 与旋转轴参数由 `M92` 给出 | 电机步距角、同步轮齿数、皮带节距、减速比、旋转半径 |
| 速度/加速度 | `M566`、`M203`、`M201` | 平台惯量、重心、共振、喷嘴接触风险、可达空间 |
| 电流 | `M906` | 电机温升、驱动散热、保持力、失步保护 |
| 行程 | `M208` | 实际软限位、夹具、工件和龙门架的碰撞边界 |
| 工具温度 | 热端 PID 与 285 °C 上限 | 传感器型号、加热器额定值、热保护、材料工艺 |

上游文件在驱动映射中采用 U/V，另一些旋转参数行使用 A/B。应把它视作该原型/固件版本中的**混合轴字母用法**，而非通用规则；移植前先查目标固件的轴字母规范，再明确旋转轴物理定义。

## Duet2 / Duex5 的作用

上游说明建议：Prusa i3 MK3S 的五轴改装可使用 Duet2 WiFi 或 Duet2 Ethernet；增加 U、V 两个步进轴时需要 Duex5 扩展板。初次接入板卡时，应遵循 Duet 官方接线和首次联网文档，而不是仅复制仓库文件。

## 归零与探测：原型行为

- `homeall.g`：先以传感器失步检测处理 X/Y，随后抬 Z、移至床面中部并执行 `G30`。
- `homez.g`：Z 轴向高端限位归零，并设置 Z 最大位置。
- `config.g`：含 `M564 H0`（允许未归零运动）；Z 探针使用 `M558 P0`（探针禁用/手动设置）。

这三个事实意味着：上游原型的归零设计不满足“任何机器的保守默认策略”。在目标机上，必须先验证物理限位、传感器状态、探针方向、软限位、旋转平台安全姿态和单轴回退路径。

## 本地移植禁区

不要直接导入以下内容：

- `sys/config.g`、`home*.g`、`pause.g`、`resume.g` 与 `cancel.g`；
- 上游的网络、SSID、工具、热端 PID、温度上限和电流；
- 任意含 U/V/A/B 的 G-code；
- 因原型行程和夹具得出的软限位；
- 用于另一个机构旋转中心的坐标偏置。

可迁移的是验证方法：先计算步距，再用小幅正反转测角；先做冷态、低速、无挤出空跑；把碰撞空间与回零流程纳入切片前检查。
