# 01｜项目概览

## 一句话说明

Open5x 是一个开源五轴 FDM 改装项目：以成熟的个人三轴打印机为基础，增加可倾转/旋转的打印平台与两个旋转自由度，并配合保形（conformal）切片，使材料能沿曲面方向沉积。

原始说明强调的目标是降低个人开发者接触五轴增材制造的门槛。它不是将五轴 CNC 或机械臂直接拿来挤出，而是围绕 3D 打印的喷嘴、热端、送料、温控、切片和 G-code 工作流进行适配。

## 原型演进

上游 README 表明硬件先后落地在 Prusa i3、Voron 和 E3D ToolChanger 等 FDM 平台；仓库中的 Jubilee 目录则提供将五轴打印平台安装到 Jubilee Z 轴系统的方案。它们共享“旋转打印平台 + 五轴路径”的思路，但结构尺寸、电机、控制器、限位、换刀和安全空间并不相同。

因此，选择某一个目录作为机械起点，并不等于可以继承另一目录的配置文件或 G-code。

## 与本工作区机器的关系

| 项目 | Open5x Prusa 原型 | 当前工作区已有机器资料 |
|---|---|---|
| 控制栈 | Duet2 / Duex5 / RepRapFirmware | Octopus Max EZ / Klipper，自定义 RTCP 历史代码 |
| 旋转轴记号 | 文件中混用 U/V 与 A/B；Jubilee 说明还使用 A/B/C 约定 | 已有系统使用 U/V 或 A/C，必须以活跃配置为准 |
| 切片工具 | Rhino + Grasshopper | 现有 RTCP G-code 与宏流程 |
| 可移植内容 | 机械概念、校准方法、碰撞仿真原则 | 不能直接复制 RRF 的 `config.g`、归零宏或五轴 G-code |

结论：Open5x 可作为五轴保形打印的机械和软件参考库；若要接入当前机器，应另行完成运动学、坐标系、旋转中心、喷嘴偏置与安全宏的适配验证。
