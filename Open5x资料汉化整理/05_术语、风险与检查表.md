# 05｜术语、风险与检查表

## 术语表

| 术语 | 中文解释 | 本资料中的使用边界 |
|---|---|---|
| FDM | 熔融沉积成形 | 挤出式 3D 打印工艺 |
| Conformal printing | 保形打印 / 随形打印 | 路径或材料沉积方向服从曲面，而非只按水平层堆叠 |
| 5-axis | 五轴 | 通常为 XYZ 三平移轴加两旋转自由度；具体轴名取决于机器 |
| U/V | 上游 Prusa 原型中新增两驱动/逻辑轴的标签 | 不是跨控制器的标准化物理定义 |
| A/B/C | 常见旋转轴约定：分别绕 X/Y/Z 轴 | Jubilee 说明明确使用此约定；RRF 原型文件也出现 A/B 参数字母，须逐行确认 |
| RTCP | 旋转刀尖点/喷嘴点补偿思想 | 目标机若采用 RTCP，旋转时需保持喷嘴目标点；上游资料没有授权将其配置直接用于当前机 |
| 旋转中心 / pivot | 平台进行旋转的几何中心 | 运动学、仿真、零位与喷嘴偏置的共同基准 |
| 软限位 | 控制器在软件内限制的行程范围 | 必须比真实干涉边界更保守，且不替代硬件限位与急停 |

## 轴名澄清：先定义物理，不要猜字母

在任一五轴系统中，先写清以下事实，再讨论 G-code：

| 应确认的问题 | 例子 |
|---|---|
| 轴绕哪根物理轴旋转？ | “平台绕机器 Y 轴俯仰” |
| 正方向如何定义？ | 从操作者视角看顺时针还是逆时针 |
| 旋转中心在机器坐标中的位置？ | `(Xp, Yp, Zp)` |
| 旋转是否改变喷嘴相对工件的位置？ | 是否由 RTCP/运动学补偿维持目标点 |
| 控制器中的字母是什么？ | 本机使用 A/C、U/V 或其他扩展轴 |
| 零位和机械安全姿态分别是什么？ | 归零角不必等于最安全的停放角 |

只有完成这张定义表，才可以解释或转换上游的 U/V、A/B/C 与目标机 G-code。

## 风险层级

| 等级 | 示例 | 处理原则 |
|---|---|---|
| 机械碰撞 | 平台撞龙门架、喷嘴撞夹具、线束被拉紧 | 优先离线仿真；设置软限位；冷态低速空跑 |
| 坐标错误 | 旋转中心偏移、零位错位、轴方向相反 | 单轴小角度正反测量；绝不直接跑完整路径 |
| 控制误配 | 细分/电流/齿比/驱动映射错误 | 按轴独立校准并记录版本；严禁照抄其他机器配置 |
| 工艺风险 | 斜面熔垂、喷嘴刮碰、熔体堆积 | 从小样、低速、无支撑样例开始，逐步放大 |
| 热风险 | 温控参数、传感器或上限不匹配 | 保留目标机器原有热保护；禁用来自参考机的 PID/温度值 |

## 上电前检查表

- [ ] 目标控制器、固件版本与实际驱动器已确认。
- [ ] 每个物理旋转轴的名称、方向、零位、传动比和软/硬限位均已写入记录。
- [ ] 平台、喷嘴、龙门架、夹具和线束的最小间隙已在全姿态范围内检查。
- [ ] 急停、停止宏和电机禁用功能可用。
- [ ] 热端与床均处于冷态，挤出机断料或明确禁用。
- [ ] 单轴小角度测试计划含返回动作和人工观察位置。

## 首次五轴路径检查表

- [ ] G-code 的单位、绝对/相对模式、旋转轴字母、角度单位和进给均已解析。
- [ ] 每个路径点都满足平台和喷嘴的行程/碰撞限制。
- [ ] 已完成无工件或简化工件的离线仿真。
- [ ] 已完成断料、冷态、低速的短段空跑，并与仿真姿态一致。
- [ ] 确认每次旋转期间喷嘴目标点的补偿策略正确。
- [ ] 首次带料测试使用短路径、可随时停机的保守参数。

## 原始资料中的明确风险提示

Voron 0、E3D ToolChanger 与 Jubilee 的上游说明均将其描述为进行中或按现状提供的原型；明确提示碰撞可能造成永久机械损伤。Jubilee 文档还特别要求换刀前后清除五轴平台顶部空间。

因此，本中文包不把上游任何几何、配置、宏或 G-code 标记为“即插即用”。
