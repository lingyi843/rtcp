# 张大头 X42S V2.0 资料

整理日期：2026-10-26。

## 图片中的型号

商品规格写明 X42S_V2.0（PLC脉冲+CAN）集成款，共两套：42-23 磁柱电机 0.13 N·m，42-40 磁柱电机 0.43 N·m。商品缩略图另印 X42S_V2.0B，实际硬件小版本以收到的板卡丝印为准。

## 附带文件

ZDT_X42S_第二代闭环步进电机用户手册_V1.0.5_20260527.pdf

这是现有本地保存的厂家手册，手册版本 V1.0.5，更新日期 2026-05-27；更新记录明确新增 2.0 板卡编码器、供电电压等说明。手册版本号与板卡 V2.0 不是同一个编号。此处没有将其称为厂家最新版本。

## 重点章节（按手册印刷页码）

- 第7–10页：板卡与固件对比、产品参数。
- 第12–22页：接口、按键、屏幕与参数菜单。
- 第23–25页：脉冲控制接线，含PLC、差分接口和3D打印主板。
- 第28页：CAN通讯接线。
- 第29–38页：回零、限位、到位、多机同步、定时返回和心跳保护。
- 第40–45页：通讯格式、CAN分包与上位机示例。
- 第46页起：通讯命令，含状态读取、运动和参数设置。
- 第108页：厂家售后与技术支持入口。

手册区分 Emm5.0 和 X 固件，控制命令与参数需对应实际装载的固件。
