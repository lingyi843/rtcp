## Decisions Made

| Decision | Reason |
|---|---|
| 使用独立 `.planning` 目录 | 不覆盖工作区里已有的五轴设备调试计划。 |
| 图片完整性按数量和 SHA-256 哈希复核 | 可证明没有新增、删除或改写图片内容。 |
| 文件改名之前先生成完整映射 | 降低同名覆盖和错配风险。 |
| 保留现有 18 个项目文件夹名称和分组 | 当前分组与报销清单行项目一致；本次只统一文件名，避免不必要的目录层级变化。 |
| 文件统一采用“项目序号及名称（金额）+资料类别” | 比旧批次单纯“照片1-6”更容易区分发票、支付凭证、实物、详情和支付记录，同时保留原项目顺序。 |
| 对重复 PDF、票面金额差异和退款进行文件名备注 | 用户要求不增减文件，显式备注比删除副本或掩盖差异更安全。 |
| 本轮只读审核，不修改用户调整后的文件 | 用户请求“审核”，未授权再次改名或移动文件。 |
| 第 16、17 项各缺两张资料图视为已知例外 | 用户明确知情，本轮不重复作为未知问题。 |
